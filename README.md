# VerdeNest

A 3D interactive business website for greenhouse structures, featuring a dynamic configurator, scroll-based animations, and a modern glassmorphism design.

## Tech Stack

- **React** (Vite)
- **Three.js** / **React Three Fiber** (3D Rendering)
- **GSAP** & **Lenis** (Scroll Animations & Smooth Scrolling)
- **Vanilla CSS** (Design System)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Customization

To customize the business details, products, and configurator options, edit the `src/data.js` file.
